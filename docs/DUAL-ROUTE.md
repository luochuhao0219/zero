# 0.9 连续展馆与双路线实现

对应 `借光-珞珈夜戏_连续动画与双路线改版任务书_V1.0.md`。实现日期 2026-11-07～08。原生 ES modules + 本地 Three.js r180；无构建/服务端数据依赖。

## 路线和职责

```text
校园（public 0→1，5 个视口）→真实三维内厅 / 明确选路
  左 museum（24 个视口）
    识影 .10 → 工坊 .31 → 故事 .52 → 光影 .73 → 编戏 .92
    → 尽头通道（z=-94）→游戏路线；或沿展廊逆行返回内厅
  右 game（14 个视口）
    穿幕 → 原灯市 → 原三维戏台 → 原三关 → 通关演出/留影/结束 → 内厅
```

- `RouteState` 只管理 route、本地 progress、transition、interaction、gameActive。End/继续向下滚动不能自行选择路线。900ms 选路转场期间拒绝重复选择；返回按路线距离延长到约 1.4～5 秒。
- `Journey` 管理原生文档滚动、路线高度、短响应缓动（`1-exp(-20*dt)`）、焦点与原游戏交接。物件拖动锁定路线进度，pointerup/cancel/lostcapture 释放锁并恢复滚动坐标；只允许最初抓取的指针移动/释放对象，第二指不接管现有拖动。
- `MuseumWorld` 复用 `PassageScene` 的 renderer / gallery scene，没有新增第三个 WebGL context。墙/地/顶/门洞/灯光/展品均有三维位置；入口 HTML 门牌投影在真实门洞上。竖屏按相机 FOV/宽高比后退，保证两门都能看到。
- `ShadowStage` 保留原三关参数、评分、94% 自动吸附、4.5 秒通关演出与留影。第三关增加“看这一夜的留影”进入原结束段，也可直接返回内厅。返回时按实际倒退位置交接戏台与灯市；若从历史馆通道进来，先退回通道，再沿历史馆回厅。
- 展馆侧栏是非模态的局部控件与补充阅读，不遮蔽全屏、不阻止参观滚动；五区本身由相机连续位置决定，不能靠逐个开弹窗参观。

## 镜头配置

`src/museum-world.js` 的 `MUSEUM_CAMERA` 是唯一展馆镜头表。每项 `[progress, position[x,y,z], lookAt[x,y,z]]`，按相邻点平滑插值；反向采样同一表。

| 本地 progress | 意图 | 关键位置 / 注视 |
|---|---|---|
| 0 / .045 | 内厅→左门 | `(0,3.1,12)` → `(-4,3.1,7)` |
| .10～.22 | 地域图、历史、藏品、传承 | 左廊 z=-2～-7，两侧注视后回中轴 |
| .28～.37 | 靠近同一影人 | z=-20～-21，注视 z=-28 |
| .43～.60 | 同影人入同一幕，原创三幕 | 注视影幕 z=-47 |
| .65～.78 | 绕过幕侧→幕后 | `(-3.5,5.5,-63)` 注视 `(-9,3,-49)` |
| .84～1 | 回幕前→自由编戏 | `(-9,3.2,-69)` 注视同一幕 z=-80 |

五站区间在 `src/route-state.js`：`[0,.22)`、`[.22,.43)`、`[.43,.64)`、`[.64,.84)`、`[.84,1]`。路标只是滚到该位置，不更换场景。工艺由 .22～.43 连续控制制皮/镂刻/敷彩/装缀；故事的位移、桥面、姿态也连续变化；标题和辅助说明按段更新。

同一 hero mesh 从藏品到工坊、故事和幕后；同一 theater group 从故事 z=-47 移动到编戏 z=-80。自由编戏的 Canvas 成为该实体幕布的实时纹理。幕后的简化点光源模型为 `scale=7/(7-depth)`、`shadowX=-lampX*(scale-1)`，与场景的灯、影人和幕同步，并非完整物理光学模拟。

## 输入与存储

- 双门：鼠标悬停/键盘聚焦亮灯；点击/Tab+Enter 选择。Home/End、原生滚动、路标均可浏览。
- 工坊手杆、实验灯/影人、编戏两演员：小范围 pointer capture；`touch-action:none` 只用于抓取把手；方向键可替代拖动。侧栏保留滑杆、换色、姿态、朝向、布景、人数和标题控件。
- 三关：数字 1～4 选物体，方向键/Q/E 微调；Ctrl/Cmd+Z 撤销，R 重置，Esc 返回内厅。
- 原键保留：`borrow-light-v1`（通关/原留影）、`borrow-light-draft-v1`（编戏草稿）、`borrow-light-compositions-v1`（最近六出自由小戏）。不迁移、不清空旧键。坏 JSON/单条坏作品有单独过滤。
- 保存将戏票从物理幕所在位置收向留影册；reduced-motion 缩短为 350ms。下载仍为 Canvas WebP；数据仅存当前浏览器，清站点数据会移除。

## 素材、预热和性能

- **本次没有新增外部图片、字体、音频或 AI 栅格素材**。新增墙、门、灯、地域示意图、标题牌为本地 Three 几何/Canvas 绘制；复用已有原创影人/景片/纸纹和校园/灯市资产。地域图是非精确位置示意；《借光过桥》是本站原创剧情；工艺为简化数字示意，不冒充历史实物复原。
- 非遗项目、地区与传承人资料复用 `explore-data.js` 的史料及来源链接，阅读资料仍可展开。已有外部资产许可分别见 `REFERENCES.md`、`MATERIAL-SOURCES.md`、`ATMOSPHERE-ASSETS.md`、`CONTINUOUS-JOURNEY.md`。
- 所有开场贴图完成后预编译 gallery/market；就绪前保持完整当前场景并拒绝进入未就绪路线。无 WebGL 2 时给出可见提示，不假装可操作三维游戏。
- 不可见的场景不渲染；暂停按 route / visibility / context 原因分别累计，恢复某一个原因不会覆盖其它暂停。
- `AdaptiveQuality` 按 150 个有效帧的中位间隔 >22ms 降级；严重卡顿走有界快路径：最近最多 20 帧全部 >100ms、至少 4 帧且累计 ≥2 秒便降一档，避免 1 FPS 下每档等 20 秒。最多四档、不自动回升；暂停/空闲清空样本，>5 秒间隔不计。戏台第一档取消反射/减少粒子并释放 MSAA 双缓冲，第二档关闭阴影/泛光，第三档释放 composer/bloom 缓冲并直接渲染，将 Standard/Physical 材质一次性换为 Lambert 顶点照明，保留几何、色彩纹理、透明裁切与动态自发光；牺牲法线、金属/清漆与屏幕特效以降低着色成本。像素比例上限依次 1.25、1、.85、.7（不提高本来更低的 DPR）。展馆采用同一分辨率策略；门户以外的稳定场景用单纹理合成，穿门/影幕期间保留三纹理转场。
- 影人 Canvas 为十张 LRU，替换纹理会 dispose，避免连续调姿态无限增长缓存。十张 960×1640 RGBA 像素约 60 MiB，仅是理论 CPU 像素预算，不是实测总内存/GPU 占用。
- reduced-motion 去掉环境摆动/鼠标环顾，主动导航即时到位，游戏和展馆静止时不持续提交 GPU 绘制；交互、布局或视角改变仍可唤起绘制。标签页隐藏时释放游戏拖动、取消待触发的自动通关，回到前台再判断；暂停原因仍相互独立。
