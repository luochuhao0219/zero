# 右侧戏台与自由开演改版 · 2026-11-11

## 流程与范围

右门路线、穿幕、灯市、三关判定与原有演出保留。第三关完成且本地记录含三关时，主要按钮变为「排一出自己的戏」。同一 WebGLRenderer、cloth 继续用于自由阶段，新增十五部件影人仅在自由阶段使用，原三关保留原骨架，镜头通过缓动靠近，未增加独立编辑弹窗或第三个 WebGL context。

已通关的用户可从戏台「续排小戏」再次进入。留影册不再提供创作/编辑/复制入口，保留通关留影、自编作品、播放、下载、确认删除。继续编辑与复制新结局从自由戏台的「旧戏票」进入，旧图像与已有完整作品存档兼容。

## 操作

- 抽故事签：樱下相逢、借灯问路、桥头送别、夜归珞珈，或自编一出。
- 挂架上的影人、箱中的灯笼/伞/书卷、景片架可点击取用，也可拖入幕内。
- 直接拖身体换站位；拖前后手经两节逆运动学让肩肘屈伸，拖脚让髋膝屈伸。选人后可拖头部低头、拖骨盆下蹲；小圆点单独调腰、肘、腕、膝。点选后可转身、收起。
- 取出的道具可自由移动，接近手部时出现亮圈提示；松手吸附跟随关节。点击「交给朱红/青绿」提供键盘可达的替代操作。
- 影人滚轮缩放；双指仅在已抓住影人时进入捏合，第三指忽略。取消、丢失 capture、关窗恢复未提交的拖动。
- 每张小戏票独立排布。点「记下这一幕」进入下一段；台词和标题直接在幕上/标题处改写。
- 键盘 1/2 选影人，方向键换站位，Q/E 转动所选关节，F 转身，+/− 缩放，Ctrl/⌘ Z 撤销。各关节的小按钮可键盘聚焦，选手/脚后方向键移动末端，选头后方向键转动颈部。
- 每幕最多三个动作：招手、点头、望月、作揖、鞠躬、递物、走路、下蹲、起身、跪礼、停顿。动作签下沿可左右拖动或用方向键调整 0.7–8 秒时长；左右箭头调整先后，▶ 单独试演。
- 点「调姿」生成 5 个关键姿势（走路 9 个），在幕上直接修改。腰部与膝盖不会拉长，关节角度有边界；走路分支撑脚和摆动脚，持物的前臂不参与摆臂，递物时手靠近后更换持有人。
- 新作按动作实际时长，加起落停顿和幕间过渡编译时间线；原作品缺少 actions 时仍按十二秒回放。采样不改草稿，舞台与封面/收藏播放器共用关节模型；切后台会停止演出和声音。减少动态效果偏好下仅保留动作关键状态。
- 声音默认关闭。配乐菜单提供月下丝弦、灯市小调、雨落庭院与静音，点击曲目即可试听，音量 0–100% 随作品保存。旧 gong 记录映射为灯市小调。保存失败保留旧作品，并提供封面下载。

## 模块

- `stage-studio.js`：戏台内界面、剧本/片段、旧戏票、存档及收藏播放器。
- `studio-controls.js`：ray-plane 拾取、身体/手杆/道具/景片拖动、持物吸附、捏合与键盘操作。
- `puppet-motion.js`：关节限幅、层级正向变换、固定肢长两节 IK、镜像坐标与双脚锁定下蹲。
- `articulated-art.js` / `articulated-rig.js`：十五个裁切部件、两款共享纹理、Three.js 关节组；仅首次进入创建，逐帧只更新变换。
- `motion-clips.js` / `motion-timeline.js`：动作库、迈步落脚、递物、关键姿势与三幕时间线。
- `studio-space.js`：纸面与原点光源投影的可逆坐标、范围、解锁条件。
- `studio-world.js`：复用原幕布与关节 mesh，背景仅在文字/灯色/场景变化时上传。
- `studio-painter.js`：共用布景、封面与收藏播放器绘制。
- `studio-storage.js`：先持久化再更新引用，按稳定 id 覆盖原作或复制新作。
- `stage-details.js`：侧台挂架、皮箱、手杆、桌面、卷轴、杯盏、戏单、观众长凳。静态木件按材质合并，无新增动态光源/阴影贴图。
- `stage-studio.css`：独立戏台界面、纸签、右侧叙述/操作排版及手机布局。

旧的 `compose-studio.js` 面板已移除。存储键仍为 `borrow-light-v1`、`borrow-light-draft-v1`、`borrow-light-compositions-v1`。草稿 version=2 沿用，新增的片段 scenery/actions、人物 present/joints 为可选字段；action.keys 的关键姿势也通过同一人物净化器限幅，最多三动作、每动作九姿势；未添加这些字段的旧作品仍能恢复。

## 美术与字体

暖纸幕、旧木、朱红皮影、青绿夜色与暗金指示。保留既有校园/灯市素材与三维建筑，补充侧台生活物件及前景座席，保持中央操作视线。没有引入新 AI 栅格或外部照片。

书法仅用于匾额、幕名和作品名。右侧叙述/按钮采用思源宋体，台词/故事签采用霞鹜文楷。两款 WOFF2 在构建时重命名为 StudioSong / StudioWenKai，保留版权与 OFL 文件。子集包含 GB2312 字表、ASCII 和本项目界面字符；未覆盖的用户输入由系统宋/楷字体回退。

- Adobe Source Han Serif 2.003R：<https://github.com/adobe-fonts/source-han-serif/releases/tag/2.003R>，`14_SourceHanSerifCN.zip` 中 `SourceHanSerifCN-Regular.otf`。
- LXGW WenKai 1.530：<https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530>，`LXGWWenKai-Regular.ttf`。
- 许可：`assets/fonts/OFL-SourceHanSerif.txt`、`assets/fonts/OFL-LXGWWenKai.txt`。子集约 1.8 MB + 1.5 MB，font-display:swap，限相应用字区域加载。
- 重建：安装 fonttools / brotli 后运行 `python scripts/fonts/build-stage-fonts.py 原始宋体.otf 原始文楷.ttf`。完整原字体仅用于构建，不随项目额外分发。

## 工具架和配乐更新

道具箱和景片按钮归入同一个流式右侧工具架，桌面间距 16px、手机间距 12px。矮屏缩小道具图标，保留按钮点击区域；空间不足时工具架单独滚动，两个分区不再绝对定位相互覆盖。

`theater-score.js` 采用 D 宫五声音阶、16 小节旋律和变化伴奏，三种编配节奏与音色不同。拨弦为短延迟弦模型，笛为带气声/揉音的加法合成，另有慢起和声、铃音、木击与小鼓；雨景使用首尾渐变的低通噪声。乐音使用 24kHz 缓冲，缓存最多 64 个音色片段、同时最多 48 个声部，90ms 预调度，后台暂停，不逐帧合成。

试听、演出和收藏回放共用配乐器；界面音量直接渐变，不重播旋律。全站配乐在独立编戏音轨播放时淡出，停止后恢复。没有新增远程音频请求、录音或自动播放。自动测试覆盖旋律/和声、波形包络、音序资源上限、雨声释放、异步启动取消、背景避让、音量与旧存档兼容。

本次实际页面验收：桌面右架间距 16px；390×844 与 390×740 手机为 12px，矮屏道具和三片景均完整显示。三首试听、暂停和音量 35% 已验证；菜单状态正确。配乐合成与全套回归共 93 项测试通过。
