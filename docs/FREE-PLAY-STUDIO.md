# 自由小戏扩展 · 2026-11-10

入口：右上角「留影册」→「继续编一出」。编辑器与收藏播放器都位于独立 dialog，未更改校园、展馆镜头和三关游戏的路线/动画代码。

## 已实现

- 四个可编辑的题目：樱下相逢、借灯问路、桥头送别、夜归珞珈；另有空白开场。题目带入布景、三段站位、动作、台词和持物。
- 起场、相遇、落幕分别保存两个人物的站位、大小、手杆角度和朝向，可沿用上一段的排布。
- 招手、作揖、指路、回望、告别五种动作预设，保留原来的滑杆与画布拖动/方向键微调。
- 每段一件道具：灯笼、纸伞或书卷，可独立摆放、拖动，也可以跟随指定影人的手。独立道具另提供位置滑杆。
- 每段最多 36 字台词；全剧支持 18 字标题、60 字简介。台词提示和正文通过 textContent / Canvas 绘制，无动态 HTML 注入。
- 暖灯、月夜、雨幕三种气氛；声音默认关闭，可主动选择合成细雨声或开场锣点。
- 12 秒演出：段内停留后平滑过渡至下一站位。播放使用草稿快照，不改编辑状态。减少动态效果偏好下按片段切换。
- 关闭、停止、切后台都会取消播放帧并关闭声音资源。影人用既有分层部件旋转，布景缓存，播放时不逐帧生成整张影人纹理。
- 新收藏支持播放、继续编辑、复制一出、下载封面、确认删除。编辑原作覆盖同一作品；复制后另存。刷新后能继续编辑已保存的原作。
- 选择题目或打开另一出戏时，可用「恢复上次草稿」撤销一次切换。

## 存储与兼容

沿用 `borrow-light-draft-v1` 和 `borrow-light-compositions-v1`，保留最近六出。草稿 version=2 增加 frames / light / sound 等字段；顶层 actors 与当前片段共享引用，兼容已有画布操控。读取时重建引用、限制范围并复制各段，旧草稿迁移为三段独立排布。

新作品保存封面 image 与完整 draft，id 用于刷新后识别正在编辑的原作。旧版只有图片的戏票保持图片收藏，可下载和删除，不伪造缺失的历史编排。

写入作品失败时保留原收藏并提示下载封面；删除仍先持久化再更新画面。通关进度的存储结构与写入流程保持原样。

- Chrome 实际操作：选择题目、动作、编辑结尾台词、完整演出、收藏、收藏播放、刷新、继续编辑、修改原作及复制新作。
