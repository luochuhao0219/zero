# 沿途拾影：增量内容扩展

2026-11-07。本次保留 0.8 的全部连续滚动路线、原素材、三维镜头及三关玩法。在其上增加五个自愿进入的探索空间，无新增运行时依赖，无远程图片请求。

## 内容与入口

- 顶部「探索」随时打开目录；门廊、室内影幕、灯市、幕后和留影段落增加对应的沿途入口。
- 识影馆：江汉皮影的地域、雕镂、声腔、口头叙事，刘年华的学艺经历，以及中国皮影与地方传统的关系。
- 影人工坊：制皮、镂刻、敷彩、装缀四步认知，原创影人的放大、换色及手杆关节示意。
- 戏摊故事：原创《借光过桥》三幕阅读线索，红衣归人、绿衣候人的角色说明；可直接进入原有对应关卡。不是传统剧目复刻，也没有替换原有通关演出。
- 光影实验：简化点光源投影；改变灯的横向位置、影人与幕的距离，对照黑影和彩色效果。与完整三维点灯关卡分开。
- 自由编戏：三个布景、一或两位影人、位置与尺寸、手势和朝向、标题；鼠标/触屏拖动、滑杆、方向键均可排布。可保存最近六张戏票并下载 WebP。

## 与主线的边界

`explore.js` 挂载原生 dialog；`explore.css` 样式以 ex- / exploration 命名隔离。主线长度及进度阈值保持不变。

打开时暂停 Journey 的进度更新、幕后台渲染和原三维操作，锁定页面滚动；展板内部独立滚动。关闭或 Esc 恢复同一归一化位置，视窗变更时也按原进度还原，不调用章节跳转。故事入口先关闭展板再进入原关卡。

新增图像均复用 `art.js` 的影人、桥、花枝、建筑和纸幕绘制函数，无素材替换。Canvas 仅在交互时重绘，没有额外动画循环。

`borrow-light-draft-v1` 保存草稿，`borrow-light-compositions-v1` 保存最近六张自由作品。与原游戏 `borrow-light-v1` 分开，不改写原关卡进度和作品；原留影册增加自由作品区，计数合并。存储不可用时仍能创作、下载，并提示本地保存失败。
