# 借光 · 珞珈夜戏

> 从武汉大学的夜色出发，循着一束光走进江汉平原皮影的世界；看一出戏如何被制作、讲述与传承，再亲手让影子登台。

**《借光》是一件可探索、可操作的网页作品。** 它以江汉平原皮影戏为文化参考，把连续的三维叙事、五柜数字展陈、互动皮影游戏与自由开演连成一段旅程。观众既能阅读资料，也能通过移动光源、拼接景片和操纵影人，感受“灯、幕、影、人”如何共同完成表演。

## 推荐体验路径

1. 运行项目后，滚动穿过校园夜路和室内长廊。在历史馆门前点击开门，进入五柜展廊。
2. **沿廊观看江汉皮影。** 可滚动前进或后退，也可点击底部编号直达展柜。走近时，画中人物以肩、肘、髋、膝等关节动作循环表演。点击大理石展签旁的金色圆圈，可打开带图片、文字和资料链接的讲解页。
3. **从馆尾走向戏台。** 看完第五柜后继续前行，拉开长廊尽头的帷幕，穿过影幕与灯市，进入三幕互动小戏：**点灯**调整光影，**搭桥**移动景片，**对戏**操纵人物。接近目标轮廓时，系统会提示契合度；达到要求并松手后，角色自动开演。
4. **排一出自己的戏。** 完成三幕后进入同一座戏台的自由开演阶段：选故事签和景片，拖动影人、关节与道具，编排动作、台词和配乐，再试演、保存。已通关的观众也可回到戏台续排；在“旧戏票”中继续编辑或复制作品。
5. 打开**留影册**，查看三幕通关留影与自编作品；作品保存在当前浏览器中，也可下载封面。

| 展柜 | 主题 | 观看重点 |
| --- | --- | --- |
| 01 光影溯源 | 起源与名录 | 从传说、历史资料和保护名录认识皮影 |
| 02 江汉经纬 | 地方与流变 | 以江河、城镇和时间线理解地域联系 |
| 03 幕后百艺 | 制作与操演 | 看皮料、刻刀、关节、操纵杆和唱腔如何协作 |
| 04 戏班与剧目 | 团队与作品 | 比较不同地区的表演和叙事方式 |
| 05 古戏新生 | 当代转化 | 关注新的舞台语言、空间和青年创作 |

## 设计表达

- **把“观看”接到“动手”。** 展廊解释皮影为何能动，三关让观众操作光源、景片与人物，自由开演再把编排交给观众。游戏是帮助理解原理的数字改编，不替代真实皮影操演。
- **让人物按关节表演。** 展柜中的肢体由独立的透明贴图片段组成，围绕关节旋转；各柜动作和道具不同，画面随镜头靠近而进入观看节奏。
- **让空间成为叙事。** 校园、长廊、展馆、影幕、灯市与戏台由开门、拉幕和连续镜头连接。观众可以逆行、跳到指定展柜或返回内厅。
- **让动作与音乐参与讲述。** 自由戏台的影人可分别调整手、脚、颈与腰部关节；可选的合成配乐会随作品保存，声音默认关闭。
- **让文化资料可追溯。** 每柜讲解附有资料来源；数字展品、背景和人物是艺术化解释，不作为馆藏文物或历史演出的复刻展示。

## 本地运行

需要 **Python 3** 和支持 **WebGL 2** 的现代浏览器。项目是静态网页，运行前无需安装前端依赖。

```sh
python3 server.py --open
```

也可在 macOS 双击 `启动预览.command`。默认打开 `http://127.0.0.1:4173/`；若端口被占用，请以终端显示的地址为准。不要直接双击 `index.html`，浏览器会限制本地模块加载。声音默认关闭，可由页面右上角主动开启。

在未开启 WebGL 2 的设备上，页面提供有限的平面预览；三维戏台的直接操作需要 WebGL 2。留影和自由编戏数据保存在当前浏览器的 `localStorage` 中，清除站点数据会删除本地记录。

## 实现与素材说明

前端使用原生 **HTML、CSS、JavaScript** 和本地打包的 **Three.js 0.180.0**；三维场景由 WebGL 绘制，环境声和可选配乐由 Web Audio 合成。项目包含响应式布局、键盘操作和系统“减少动态效果”适配。慢帧时会逐级降低画面负担，以保证交互继续可用。

建筑、影人关节、互动和页面布局由项目实现。部分场景、皮影部件、窗景和材质视觉使用生成图像辅助制作；木材、石板等表面贴图包含 Poly Haven 的 CC0 素材；展柜讲解中的五张照片由项目组提供，原图水印保留。**素材来源与许可**见 [文化与设计参考](docs/REFERENCES.md)、[材质来源](docs/MATERIAL-SOURCES.md) 和 [展馆修改记录](docs/江汉展馆修改-2026-11-11.md)。作品使用江汉平原皮影戏作为文化参考，不宣称数字造型是馆藏扫描件或传统剧目的完整复原。
