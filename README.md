互动皮影文化网站，当前为 0.9 连续双路线版。校园道路与入楼开场保留；到达真实三维内厅后，明确选择左侧历史馆或右侧皮影戏台。历史馆五段在同一可逆展廊中展开，游戏路线沿影幕、灯市抵达原三关戏台。两条路线均可返回内厅，不会继续滚动就自动分流。

## 启动

macOS：双击本文件夹内的 `启动预览.command`。浏览器会自动打开预览。保持弹出的终端窗口运行，关闭窗口或按 Control+C 会停止服务。

也可以在本文件夹内运行：

```sh
python3 server.py --open
```

默认地址为 `http://127.0.0.1:4173/`。端口占用时会自动尝试下一端口，以终端显示为准。需要 Python 3；前端运行无安装步骤。不要直接双击 `index.html`，浏览器的本地文件安全规则会阻止模块加载。

## 如何游玩

滚动鼠标或在手机上滑动控制镜头，停滚即停叙事；鼠标可小幅环顾。先走进教学楼，再点击门洞上的入口（键盘可 Tab + Enter）。历史馆依次经过识影馆、工坊、原创三幕故事、幕后光影实验和自由编戏；向上滚动可逆行。戏台路线继续穿幕进入灯市、抵达游戏；顶部“穿幕／灯市／入戏／留影”是游戏路线的快捷导航。声音默认关闭。

1. 滚动到“这一出，由你开场”，点击“接过手杆”；右上角“去玩”可随时直达。戏台底部也可以选择任一幕。
2. 第一幕在幕后直接拖动灯的位置，抓住影人的身体向幕布推近或拉远。在幕前也可直接拖动影子，拖角上的缩放手柄或使用滚轮改变大小。
3. 第二幕拖动右侧桥面，调整位置与前后距离；抓住桥端圆点旋转，或使用滚轮旋转。
4. 第三幕拖身体调整间距，抓住手杆绕肩膀画弧，调整两人的手势。
5. 契合度达到 94% 后松手，画面会吸附到目标并自动演出，然后显示完成提示。没有滑杆、参数侧栏或手动过关按钮。
6. 拖动空白处转动视角，空格切换幕前 / 幕后。鼠标和单指触摸都可以抓取物体。
7. 声音默认关闭。问号打开说明，Esc 或“返回内厅”沿路线返回教学楼内厅；R 重置，Ctrl / ⌘ Z 撤销。在戏台获得键盘焦点后，数字键 1–4 选择物体，方向键移动，Q / E 调整角度或距离。

三幕分别为：点灯（投影位置和尺度）、搭桥（景片投影与拼接）、对戏（关节姿态和角色间距）。金色轮廓是目标，关卡没有时间限制。玩法属于当代数字改编，不是对真实皮影演出或教学流程的完整模拟。

## 技术与原创说明

- 原生 HTML、CSS、JavaScript。未使用预设样式库、网站模板或现成游戏项目。
- 唯一运行时第三方库为 Three.js 0.180.0，用于 WebGL 三维渲染，包含其官方圆角几何、网格合并、平面反射与后期处理插件。库已放在 `vendor/`，同时附上原始 MIT 许可文件；各模块用途列于 `docs/REFERENCES.md`。
- 中文标题采用钟齐志莽行书（Zhi Mang Xing），包括标志、关卡、主要按钮、戏台匾额与新生成的留影标题；小字说明使用系统无衬线字体。英文字体为 Inter Tight 可变字体。两款字体均来自 Google Fonts 官方仓库，按 SIL OFL 许可在 `assets/fonts/` 中随附，没有分发参考网站的商业字体。
- 戏台网格、影人纹样、景片、界面、玩法、判定、视角动画、音效与存档逻辑均为本项目编写。
- 穿幕旅程复用夜市、影人和近景樟树贴图，新增内置 imagegen 生成的建筑入口与室内展演间。道路中不再放独立戏棚；建筑门洞与室内影幕分别通过实时遮罩连接三处场景。图片提供细节，相机和独立景片提供视差。校园为原创艺术化场景，最新素材、提示词与实现见 `docs/CONTINUOUS-JOURNEY.md`，早期记录见 `docs/PASSAGE-DESIGN.md`。
- 0.8 将后半段戏台展示与留影结尾接入同一滚动进度，支持前进、环绕幕后和抬高拉远。旧版本的道路戏棚已退出开场加载，素材留作版本记录。
- 木材、石板与织物的物理材质贴图来自 Poly Haven 的 CC0 资产，随项目离线分发。来源、作者、许可、文件校验值与分辨率列于 `docs/MATERIAL-SOURCES.md`，这些实拍表面贴图不是本项目原创。
- 夜市街巷、摊位和观众采用内置 imagegen 生成的三张独立贴图，通过环形背景与分层平面摆放，配合轻摆灯笼、升腾蒸汽和观众轻微姿态变化。不是武大校园或某条历史街巷的实景照片。原图、完整提示词及使用说明见 `docs/ATMOSPHERE-ASSETS.md`。
- 戏台包含 1570 片实例化曲面瓦、圆角木梁、斗拱、格栅、石础与台阶。静态结构按材质合并网格；冷暖灯光、两路 2048² 阴影、湿石板实时平面反射、薄雾与轻度泛光共同组成夜景。纸幕为 2048 × 1120，影人纹理为 960 × 1640。
- 光影按点光源、影人平面与幕布平面的几何关系计算。静态纸张与影人部件在初始化时上传为纹理，身体和两臂在 GPU 上独立变换，实时投影不再逐帧重画、上传整张幕布。Canvas 合成用于下载留影和无 WebGL 的降级显示。并非真实光线追踪或实体半透明光谱模拟。
- 影人本身采用带镂空纹样的平面片状模型，置于真实三维戏台内，符合皮影薄片的呈现方式。影人的服饰纹样与造型为原创艺术化设计，不是馆藏文物扫描数据。
- 音效是 Web Audio 原创合成的风声、细碎环境声与轻柔泛音，随旅程位置交叉变化，没有使用唱段或真人录音。
- 支持桌面与移动端响应式布局、减少动态效果偏好、键盘导航和操作说明。无 WebGL 时仅提供平面预览，直接操控游戏需要 WebGL 2。
- 介绍页保留浏览器原生滚动，不接管滚轮。离开可见范围后，开场和戏台停止绘制；进入游戏后介绍区域暂停并退出键盘焦点顺序，返回网站后恢复。减少动态效果模式关闭影人的待机和鼠标摆动，保留主动滚动与直接操作。
- 拖动由指针射线与操作平面的交点计算；关节使用肩部旋转、深度使用投影轴约束。物体位置连续跟随指针，画面保留拉幕、待机、运镜、布局转场和通关演出。动画使用时间增量驱动；帷幕开合时更新阴影，稳定后复用并定期刷新。桌面戏台像素比例上限为 2，窄屏为 1.25；展馆上限为 1.6 / 1。持续慢帧触发四档降级，依次减少反射、粒子、阴影与泛光，必要时降至 0.7 倍分辨率。后台标签暂停三维绘制。

## 当前范围

这是一版可演示的本地 WebGL 原型，三个关卡共用同一座三维戏台。当前仍使用程序建模、片状影人和传统光栅化，未达到《黑神话：悟空》这样的成品游戏美术规模，也没有光线追踪或高精扫描角色。留影与过关记录只保存在当前浏览器的 localStorage 中，未接数据库或服务器存档，不能作为比赛“数据后台”的完成证明。清理浏览器数据会删除本地记录，可先下载留影。

`server.py` 是静态文件服务器，不是游戏后端。三幕可自由访问，便于现场演示；未加入排行榜、多人玩法或完整唱腔。正式提交前还需补齐队伍信息、完整与匿名两套打包、库及用途声明，并核对主办方对游戏框架模块及 AI 辅助的解释。

## 沿途拾影内容扩展

五段历史馆已经从旧弹窗改为同一连续三维场景。长史料可在局部侧栏按需展开，主要参观不依赖打开弹窗。可在幕后的真实灯／影人把手上做实验，并在同一张幕上排演、选景、写标题、保存戏票和下载。

自由编戏从留影册进入，支持四个小戏题目、动作与道具、三段台词编排和 12 秒演出。新收藏可播放、继续编辑、复制新结局、下载封面及删除；保留最近六出及自动草稿，旧版图片留影继续兼容。实现与验证说明见 `docs/FREE-PLAY-STUDIO.md`。逆向参观或切换路线不会清空存储。从编戏尽头可沿连接通道进入游戏，也可返回内厅。旧 `docs/EXPLORATION.md` 仅供原内容与资料来源追溯，当前路线、镜头、输入和素材说明以 `docs/DUAL-ROUTE.md` 为准。
