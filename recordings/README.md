# 0.9 双路线操作录像

- `museum-route.webm`：校园、内厅、历史馆五区，工坊操杆、灯/影人实验、自由编戏拖演员、保存收票，逆向回厅与馆末通道进入灯市后返回。
- `game-route.webm`：校园、内厅右门、穿幕/灯市/戏台，幕前幕后、原三关真实操作与演出、留影册、返回。

使用 agent-browser 原生录屏；对应复现脚本位于 `scripts/qa/record-*.sh`。非静态截图拼接，也未注入通关状态。录屏捕获帧率不是应用 FPS；性能以 `docs/qa/desktop-*.json` 的独立、非录屏 rAF 样本为准。

实际验收范围、软件渲染环境、下载工具限制与待完成的实体设备检查，见 `docs/ACCEPTANCE-2026-11-08.md`。历史 v8 截图不作为本次录像证据。

文件校验：历史馆录像 60.200 秒 / 5,151,210 字节；游戏录像 17.200 秒 / 1,528,495 字节。截屏流可能压缩实际等待的墙钟时间，不能据此推导路线游览时长或页面帧率。
